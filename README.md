# 亮句 · Liangju LED

把想说的话变成手持 LED 灯牌。支持 Android 14 及以上、arm64 手机；黑底荧光黄配色，轻透玻璃卡片与点阵语音气泡图标。

![应用图标](assets/icon/liangju-icon-512.png)

## 项目结构

- **`android-app/`**：原生 Kotlin 安卓应用，系统语音识别与按需下载的本地 AI，提供可选离线语音备用。
- **`liangju/`**：React 界面预览，保留 Pixel / iPhone 模拟器。网页中的语音和 AI 仍是明确标记的预设演示，真实功能在安卓应用内运行。
- **`assets/icon/`**：图标主图和分发尺寸。

## 安卓功能

1. 点击说话，默认使用手机系统语音直接转文字；无需下载 AI，单次最长 20 秒。
2. 设置中按需开启本地 AI，自动弹出模型下载进度；完成后纠错、去除重复口头语、提炼短句。
3. 同时保留原话与可编辑结果，用户确认后再亮屏。
4. 支持四个方向连续滚动、静止显示、六种颜色、五档速度、50%–180% 字体大小、点阵 / 普通字体、全屏旋转。
5. 循环文字间隔约两个字符，不等待上一整屏退出后再重播。
6. 设置末尾提供“关于”，包含作者、说明、版本与 GitHub 地址。

## 离线模型与隐私

安装包不包含模型，AI 默认关闭。首次在“设置”开启 AI 时自动下载所选模型，显示百分比和下载量，建议使用 Wi-Fi：

| 用途 | 模型 / 引擎 | 下载大小 |
| --- | --- | --- |
| 离线语音备用（可选） | SenseVoice int8 / sherpa-onnx 2.0.1 | 约 240 MB |
| 轻量 AI（默认） | Qwen2.5-0.5B-Instruct Q4_K_M / llama.cpp | 约 491 MB |
| 增强 AI（可选） | Qwen2.5-1.5B-Instruct Q4_K_M / llama.cpp | 约 1.12 GB |

模型来自固定版本的 Hugging Face 地址，支持断点续传，完成 SHA-256 校验后才标记可用。普通语音输入不需要这些文件。开启 AI 只需下载所选一款 AI，默认约 491 MB；离线语音模型独立可选。取消或失败后开关恢复关闭，已下载模型在关闭 AI 后不会运行，再次开启也不重复下载。网络无法连接模型源时可稍后继续下载，也可将清单中的文件传到手机，在模型设置中选择“从文件导入模型”。导入同样检查大小与 SHA-256。

本地 AI 和可选 SenseVoice 下载后可断网使用；系统语音的联网和音频处理方式由手机服务决定。应用不自行保存录音文件；当前文字与样式存于应用私有目录。切到后台会停止录音和 AI 任务。模型下载可取消，未完成部分保留供下次续传。

轻量模式优先体积与速度，增强模式适合更复杂的纠错和提炼。两款小模型都有理解和纠错能力限制。程序检查输出格式、数字变化和否定词变化及常见人物关系变化，异常时保留原话，但不能保证所有人名、地点与语义都正确。请在亮屏前核对。性能与耗电需在具体手机实测。
